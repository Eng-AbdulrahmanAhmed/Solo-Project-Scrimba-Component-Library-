# Scrimba Component Library

A small, reusable **React + TypeScript** component library built as a Scrimba solo project.

## Purpose

The goal of this project is to build a collection of self-contained, typed, reusable UI
components that can be dropped into any React application. Each component is typed with
TypeScript and ships with its own CSS, so it can be used without extra setup.

## Components

- **Banner** — multi-line and single-line status banners (success, warning, error, info)
- **Badge** — square and pill badges in multiple colors
- **Card** — in progress
- **Testimonial** — with-image and no-image layouts

## Tech Stack

- React
- TypeScript
- Vite

## Getting Started

```bash
npm install
npm run dev
```
